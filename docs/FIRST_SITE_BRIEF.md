# First site brief (draft, needs approval)

Spec first, build second. Pick one, edit, then we drive it through the in-app agent.

## Recommendation: A. Agentic-systems consultancy landing page (goal G3)
One page that turns a visitor into a booked call.

**Audience:** small teams and IT leads who want AI workflows that save ops time.
**Offer:** fixed-scope "WorkOps automation sprint" (name and price to be set by you).
**Sections:** hero with one promise, three outcomes, how it works (3 steps), proof placeholder, FAQ, call-to-action.
**Not in scope:** blog, CMS, payments, accounts.

### Done when (each checked with a real browser, not by eye on code)
1. Page renders at 375px, 768px, 1280px with no horizontal scroll.
2. One primary call-to-action, repeated at top and bottom, same target.
3. No placeholder lorem text; every claim is one you can back up.
4. Lighthouse accessibility 90 or higher; all images have alt text.
5. No external requests except fonts you approve.
6. Source files saved in the project workspace and exported to a git repo.
